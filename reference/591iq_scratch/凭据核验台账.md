## 二、门户 JSESSIONID（`serverbench.log` 内 12 个）—— 全部失效

判据：`GET /account/user!getGrantedMenuTree.action`（文档记载的登录判据：
非空菜单树 = 已登录）。

⚠️ **不能用验证码图判活**：`/security/jcaptcha.jpg` 对**垃圾 JSESSIONID 同样
返回 200 + 图片**（实测垃圾值/空值/格式非法值均为 200，2.3~3.2 KB）——
那张图谁都能取，不构成会话有效的证据。初次核验正是被这一点误导，
后改用菜单树端点并以垃圾值做基准对照才得出结论。

| 结果 | 数量 | 说明 |
|---|---|---|
| ✅ 有效 | **0 / 12** | — |
| ❌ 失效 | **12 / 12** | 均返回 2 bytes 空响应，与垃圾值基准完全一致 |

`serverbench.log` / `serverbench.log.err` 保留即可，其中的门户域名
`xmyz.xmedu.cn` 属公开信息，不构成凭据泄露。

## 五、复现核验方法

```python
# ssoToken 判活
Http(token).login()   # 抛 IQError「登录失败」= 已失效

# JSESSIONID 判活（必须用登录判据端点，不能用验证码图）
GET https://xmyz.xmedu.cn/account/user!getGrantedMenuTree.action
Cookie: JSESSIONID=<值>
# 返回非空菜单树 = 有效；返回 2 bytes 空 = 与垃圾值一致 = 已失效
```

**判据纪律**：任何「有效性」结论都必须**先用一个明显无效的值做基准对照**。
本次若不校准，就会把 12 个已失效的会话误报成「全部有效」。
