处置路线 · 前两项纯删除，10 分钟减重 6.7 MB

  1. 清理打包垃圾

    剔除 255 个 .git 条目、pytest 缓存 5 条、pyc 4 条、package-lock。对内容零风险。

  2. 消除字节级重复

    期刊分区表抽至共享 assets 保留一份；跨 skill 复制的飞书/PPT/文献模板与校验脚本一并收敛。

  3. 补齐入口导航

    最高优先级内容工作：为 69 个零链接的 SKILL.md 补 references 索引表。缺这一步，知识密度等于零。

  4. 回填 frontmatter

    补 81 个 version、76 个 metadata.requires，并按实际运行核对 ppt / sheet / pdf 的 Python 依赖。

  5. 收敛命名重叠域

    medical-literature-* 4 个、product-* 5 个、contract-* 3 个各自互斥判定，本可合并为一个 skill + 多个 mode。

  6. 归一 LICENSE

    99 个无授权声明，需确认内部使用边界或统一补 Apache-2.0。

  7. 补测试

    仅 7 个带 tests/。可复用范式：product-qa 的 49 KB 回归集、book-writer 的三个 .mjs 测试。
